Geographical Maps in BRIDGES

How does the Map API work BRIDGES?

Maps in BRIDGES are retrieved from GeoJSON descriptions of the map geometry. Currently, we support both the US map and World map. The current interface permits US maps to be colored by state or by county. The color can reflect any user chose attibute, such as population, sales, crime rates, etc. and dependent on the data being mapped to the state. Counties

Counties for the US map can also be displayed and attributes assigned similar to states. For instance, election data can be mapped to each county for a more detail look of voting patterns over the years. In addition, maps can be a background for other BRIDGES data structures. For instance, you can imaging graph problems being solved as a function of the US cities (Minimum Spanning Tree, Traveling Salesman Problem, etc.) In this tutorial, we will illustrate the basic UI capabilities of BRIDGES Maps that will be helpful in building map based assignments.
